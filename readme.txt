把国内货代/跨境专线给的报价单（CSV）直接导入 WooCommerce，按目的国分区、重量段、体积重和附加费自动计算跨境运费。

== Description ==

做跨境独立站时，最麻烦的一步往往不是建站，而是回答「这一单该收多少运费」。

货代给的是 Excel 报价单：按国家分区（1区/2区/A区），按重量分档（0.001–0.1kg、0.101–0.2kg…），
每档有单价、挂号费、操作费、最低消费，偶尔还有燃油和偏远地区附加费。
而 WooCommerce 自带的配送方式只支持「统一费率」「免费配送」「按重量分档的固定价」，
要照着报价单一条条手填，一个线路几十上百个格子，改一次价格就得重来一遍。

这个插件解决的就是这一件事：**把报价单直接喂进去**。

= 核心能力 =

* **报价单 CSV 导入**：中文或英文表头自动识别，UTF-8 / GBK（中文 Excel 默认编码）都能读，逗号、制表符、分号都行。
* **分区自动映射**：报价单里的「1区/2区」自动对应到国家代码，没被命中的国家可以走 `*` 兜底分区。
* **两种计价模型**：按重量段查表（小包常见），或首重 + 续重（快递/专线常见）。
* **体积重**：长×宽×高÷系数，系数可配（6000 / 5000 / 8000），取实重与体积重的较大值。
* **重量进位**：支持 0.001/0.01/0.1/0.5/1kg 进位、四舍五入或精确计费。
* **附加费**：燃油附加费（按比例）、偏远地区附加费、每票固定处理费、最低消费。
* **多币种换算**：报价单是人民币、商店收美元时，按设定汇率自动换算。
* **后台试算器**：输入目的国、实重、尺寸，立刻看到体积重、计费重和逐项费用，方便核对报价单。
* **WooCommerce 配送方式**：可以放进任意配送区域，支持满额免运费、结算页展示费用明细。

= 数据流程 =

1. 建「线路」（一个物流产品一条线路）。
2. 上传报价单 CSV，先预览，确认后写入。
3. 在 WooCommerce「配送区域」里添加「跨境物流运费」，选择线路。

插件自身不联网、不调用任何第三方 API，所有报价数据都存在你自己的数据库里。

= 不做什么 =

* 不负责向货代下单、不生成运单、不查物流轨迹。插件只解决「算运费」这一件事。
* 不做真实装箱算法。体积重按三种近似方式取数（单件最大尺寸 / 各向相加 / 固定箱规），
  需要精确装箱可以接 `cbsr_package_dimensions` / `cbsr_package_data` 过滤器自己实现。

= 从 Excel 准备 CSV =

1. 在 Excel / WPS 里整理成一张表，至少包含「分区」和「单价」两列。
2. 建议列：分区、分区名称、国家、重量段、单价、挂号费、操作费、最低消费。
3. 「重量段」可以写成 `0.001-0.1`，也可以拆成「重量下限」「重量上限」两列。
4. 另存为 CSV（逗号分隔）。编码不用管，UTF-8 和 GBK 都能读。

示例见插件目录下的 `samples/example-rates.csv`。

== Installation ==

1. 上传 `crossborder-shipping-rates` 文件夹到 `/wp-content/plugins/`，或在后台「插件 → 安装插件」上传 zip。
2. 启用插件（需要先启用 WooCommerce）。
3. 后台左侧出现「跨境运费」菜单。

== Frequently Asked Questions ==

= 支持哪些物流商？ =

计价方式是通用的：任何「按分区 + 重量段」报价的货代、专线、小包、快递代理都能用。
插件不绑定具体物流商，因为报价单本身就是各家的通用语言。

= 报价单里同一个分区有很多行，每行都要填国家吗？ =

不用。同一个分区只有第一行需要填国家代码，后面留空会自动沿用。
分区列本身留空时也会沿用上一行（适配合并单元格导出的表格）。

= 重量段有缺口会怎样？ =

计费重落在两档之间时，插件会按「上一档上限 < 计费重 ≤ 本档上限」的规则匹配；
如果计费重低于某档下限（报价单有缺口），前台会算不出价并按你的设置隐藏或提示。
导入时会检查重叠区间并给出警告。

= 前端算不出运费怎么办？ =

常见原因：分区没填目的国、重量超出报价表最大档、报价表为空。
先用「跨境运费 → 运费试算」定位问题，再检查对应分区。

= 会和我现有的缓存/多语言插件冲突吗？ =

插件只注册一个 WooCommerce 配送方式，不改主题模板。
多语言站点需要给配送方式名称做翻译（默认走 WordPress 的 gettext）。
